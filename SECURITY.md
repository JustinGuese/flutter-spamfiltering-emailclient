# Security Policy

## Reporting Vulnerabilities

We take the security of DataFortress seriously. If you identify a security vulnerability, please do not disclose it publicly or file a public GitHub issue.

Instead, please report security vulnerabilities using **GitHub Private Vulnerability Reporting**:
1. Open the repository on GitHub.
2. Select the **Security** tab.
3. Under "Reporting", click **Report a vulnerability** to submit an advisory privately.

## Scope

This security policy applies to:
- The DataFortress client application (`app/`)
- The pure Dart filtering library (`packages/spam_core/`)

Hosted collective defense services and auxiliary infrastructure are operated separately and are outside the scope of this repository.

## What to Include

To help us assess and resolve the issue quickly, please provide:
- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal proof of concept (PoC).
- Affected versions, platforms, or environment configurations.
- Any suggested remediations or workarounds.

All legitimate vulnerability reports will be reviewed promptly, and fixes will be coordinated through responsible disclosure.
